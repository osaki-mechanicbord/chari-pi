CHARI-PI（チャリッピー）

自転車安全ナビゲーションアプリ

アプリについて

CHARI-PIは、自転車走行中の安全を守るリアルタイム交通標識警告ナビアプリです。GPS位置情報を使って、一時停止標識、信号機、一方通行などの交通標識に近づくと、音声と振動で事前に警告します。
